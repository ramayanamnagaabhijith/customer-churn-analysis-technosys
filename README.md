# Customer Churn Prediction & Retention Analysis – Teknosys Inc.

## Overview
This project simulates a client engagement at Teknosys Inc., where a telecom dataset is analyzed to predict customer churn and improve retention strategies.

## Objectives
- Analyze customer behavior
- Predict churn using Logistic Regression
- Provide business insights

## Tools Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn

## Key Insights
- Month-to-month contracts have higher churn
- High monthly charges increase churn
- Short tenure customers churn more

## Business Recommendations
- Promote long-term contracts
- Offer retention incentives
- Improve onboarding for new users
